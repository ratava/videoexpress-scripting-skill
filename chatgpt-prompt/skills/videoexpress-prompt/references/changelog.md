## 1.2

### Headline

- **Festive styles and scenes for Christmas.** Four new Christmas styles: Christmas Diorama (a glossy ceramic miniature village on a fireplace mantel), Snow Globe (a tiny scene inside a glass globe, snow swirling), Gingerbread (a world baked from gingerbread, piped icing and sweets) and Holiday Stop-Motion (a 1960s TV-special look with felt-and-wood puppets). Plus two festive add-ons for any style: Festive Winter (snow, frost, icicles, fairy lights) and Festive Summer (sunshine, tinsel, Christmas bush, Santa hats at the barbecue, no snow) for the half of the world that has Christmas in summer. Tested across 2D, 3D, craft, painted and print styles, with tips for limited-palette and character styles.

### New

- **18 new styles:** Greyscale Airbrush, Steampunk, Flat Vector Explainer, Marker Doodle, Modern 2D Cartoon, Chibi, Crayon Drawing, Impressionist, Colour Comic, Game Cinematic, Fantasy Painting, Travel Poster, Tilt-Shift Miniature, Voxel, Folk Art, Vintage Horror, Stickman, Miniature Pan. Each has its own sheet in the styles index, and many name the closest Artistly style.
- **Consistent voices.** When a character will speak in more than one clip, the skill can point you to VideoExpress's Voice Changer and the voice samples it needs, so the voice stays the same from clip to clip.
- **Reference Photo 2 for a location.** Besides a second character, the second Consistent Character slot can hold an empty location (the set with no one in it), so the same place keeps its layout across start images.
- **Artistly, CloneVoice.ai and TalkingPhotos.ai.** When one of VideoExpress's companion products would help and you don't have it, the skill names it once with a link (an affiliate link, said so beside it). Everything still works with VideoExpress alone.
